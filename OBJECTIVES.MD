The goal of Chinanki is to become the ultimate tool for learning Chinese vocabulary. It should be a better Anki version, focusing on mandarin.

Main features :
Vocabulary daily cards with more than 2 sides :
    - Word
    - Translation
    - Pinyin (for tones)

The goal of this would be to be able to go from one to another, except * -> word, this will be a future feature where you can draw the character.

The user self-checks if he knows the answer, then he selects the level of knowledge, which is used to schedule the next review.
