# Chinanki Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an installable, offline-first mobile web app for learning Mandarin vocabulary with multi-directional flashcards scheduled by FSRS.

**Architecture:** A local-only PWA. All state lives in IndexedDB (via Dexie) on the device — no server, no accounts. The domain logic (pinyin parsing, FSRS scheduling, queue building, statistics) is written as pure, dependency-free TypeScript modules under `src/lib/`, each unit-tested in isolation; React components are thin views over Dexie live queries. A build-time script converts CC-CEDICT into sharded JSON served from `public/dict/` for hanzi auto-fill.

**Tech Stack:** TypeScript, React 19, Vite, Tailwind CSS v4, Dexie 4 (+ `dexie-react-hooks`), React Router 7, `vite-plugin-pwa`, Recharts (dashboard charts), Vitest + `fake-indexeddb` + Testing Library (unit/integration), Playwright (E2E smoke).

## Global Constraints

- **Node.js 20+**, package manager `npm`.
- **TypeScript strict mode on.** No `any` in committed code; use `unknown` + narrowing.
- **No backend, no network calls at runtime.** The only fetches are same-origin requests to `/dict/*.json`. The app must fully function in airplane mode after first load.
- **No new runtime dependencies** beyond those listed in Tech Stack without stating why in the commit message.
- **Card directions are exactly four**, never more: `hanzi-meaning`, `hanzi-pinyin`, `meaning-pinyin`, `pinyin-meaning`. Nothing prompts *for* the hanzi (handwriting input is a future feature).
- **Ratings are exactly four**: `1 = Again`, `2 = Hard`, `3 = Good`, `4 = Easy`.
- **All timestamps are `number` (ms since epoch, UTC).** Never store `Date` objects in IndexedDB. Never store local-formatted date strings.
- **All durations in domain code are days** (floating point) except learning steps, which are **minutes** (integers).
- **Mobile-first.** Design for a 360×640 viewport first; tap targets ≥ 44px. Desktop is a centred column, max-width 480px.
- **CC-CEDICT is CC-BY-SA 4.0.** The Settings page must carry the attribution string: `Dictionary data from CC-CEDICT, licensed CC BY-SA 4.0. https://www.mdbg.net/chinese/dictionary?page=cc-cedict`
- **TDD is mandatory.** Every task writes the failing test first, watches it fail, then implements. Commit at the end of every task.

## Domain Model (read before Task 4)

```
Deck 1──n Note 1──n Card 1──n ReviewLog
```

- A **Note** is one vocabulary item: `hanzi`, `pinyin` (accented, e.g. `nǐ hǎo`), `meaning`.
- A **Card** is (Note × Direction). Each carries its own independent FSRS state. A deck enables a subset of the four directions; enabling a direction creates the missing cards, disabling deletes them.
- A **ReviewLog** row is appended on every answer and is never mutated. All statistics are derived from it.

```ts
import type { Tone } from '@/lib/pinyin/types';

/** Index into each array is the tone number; index 0 is the unmarked vowel. */
const MARKS: Record<string, readonly string[]> = {
  a: ['a', 'ā', 'á', 'ǎ', 'à'],
  e: ['e', 'ē', 'é', 'ě', 'è'],
  i: ['i', 'ī', 'í', 'ǐ', 'ì'],
  o: ['o', 'ō', 'ó', 'ǒ', 'ò'],
  u: ['u', 'ū', 'ú', 'ǔ', 'ù'],
  'ü': ['ü', 'ǖ', 'ǘ', 'ǚ', 'ǜ'],
};

const VOWELS = 'aeiouü';

/** CC-CEDICT writes ü as "u:"; users often type "v". */
export function normaliseUmlaut(syllable: string): string {
  return syllable.replace(/u:/g, 'ü').replace(/v/g, 'ü').replace(/U:/g, 'Ü');
}

/**
 * Standard placement: mark the "a" if there is one, else the "o" or "e",
 * else the last vowel (which handles "iu" → "iù" and "ui" → "uì").
 */
function markIndex(syllable: string): number {
  const a = syllable.indexOf('a');
  if (a >= 0) return a;
  const o = syllable.indexOf('o');
  if (o >= 0) return o;
  const e = syllable.indexOf('e');
  if (e >= 0) return e;
  for (let i = syllable.length - 1; i >= 0; i--) {
    if (VOWELS.includes(syllable[i]!)) return i;
  }
  return -1;
}

export function applyToneMark(syllable: string, tone: Tone): string {
  const normalised = normaliseUmlaut(syllable.toLowerCase());
  if (tone === 0) return normalised;
  const index = markIndex(normalised);
  if (index < 0) return normalised;
  const vowel = normalised[index]!;
  const marked = MARKS[vowel]?.[tone];
  if (!marked) return normalised;
  return normalised.slice(0, index) + marked + normalised.slice(index + 1);
}

/** Reverse lookup: accented vowel → its tone number. Built once at module load. */
const TONE_OF_CHAR = new Map<string, Tone>();
for (const forms of Object.values(MARKS)) {
  for (let tone = 1; tone <= 4; tone++) {
    TONE_OF_CHAR.set(forms[tone]!, tone as Tone);
  }
}

export function toneOfAccentedSyllable(syllable: string): Tone {
  for (const char of syllable) {
    const tone = TONE_OF_CHAR.get(char);
    if (tone !== undefined) return tone;
  }
  return 0;
}
```

- [ ] **Step 7: Implement numbered pinyin parsing**

`src/lib/pinyin/numbered.ts`:

```ts
import { applyToneMark } from '@/lib/pinyin/tones';
import type { PinyinToken, Tone } from '@/lib/pinyin/types';

/** A pinyin syllable in CC-CEDICT notation, e.g. "hao3", "lu:4", "er". */
const SYLLABLE = /^[a-zA-ZüÜ]+(?::)?[a-zA-Z]*[1-5]?$/;
/** Splits into word-ish runs and everything else, keeping both. */
const SPLITTER = /([a-zA-Z:ü]+[1-5]?)/;

function isPinyinSyllable(token: string): boolean {
  if (!SYLLABLE.test(token)) return false;
  // A bare uppercase letter such as the "X" in "X光" is not a syllable.
  return /[aeiouüvAEIOUÜV]/.test(token) || /^[nm]g?[1-5]?$/i.test(token);
}

export function parseNumberedPinyin(input: string): PinyinToken[] {
  const tokens: PinyinToken[] = [];
  for (const part of input.split(SPLITTER)) {
    if (part === '') continue;
    if (!isPinyinSyllable(part)) {
      tokens.push({ text: part, tone: null });
      continue;
    }
    const match = /[1-5]$/.exec(part);
    const digit = match ? Number(match[0]) : 5;
    const tone: Tone = digit === 5 ? 0 : (digit as Tone);
    const body = match ? part.slice(0, -1) : part;
    tokens.push({ text: applyToneMark(body, tone), tone });
  }
  return mergeSeparators(tokens);
}

/** Adjacent uncoloured tokens render as one span. */
function mergeSeparators(tokens: PinyinToken[]): PinyinToken[] {
  const merged: PinyinToken[] = [];
  for (const token of tokens) {
    const previous = merged[merged.length - 1];
    if (token.tone === null && previous && previous.tone === null) {
      previous.text += token.text;
    } else {
      merged.push({ ...token });
    }
  }
  return merged;
}

export function numberedToAccented(input: string): string {
  return parseNumberedPinyin(input)
    .map((token) => token.text)
    .join('');
}
```

```ts
import type { Rating } from '@/lib/fsrs/types';

/** FSRS-4.5 forgetting-curve constants. */
const DECAY = -0.5;
const FACTOR = Math.pow(0.9, 1 / DECAY) - 1; // = 19/81

const MIN_DIFFICULTY = 1;
const MAX_DIFFICULTY = 10;
const MIN_STABILITY = 0.1;

function clamp(value: number, min: number, max: number): number {
  return Math.min(Math.max(value, min), max);
}

/** Probability of recall after `elapsedDays` given memory `stability` (days). */
export function retrievability(elapsedDays: number, stability: number): number {
  if (stability <= 0) return 0;
  return Math.pow(1 + (FACTOR * elapsedDays) / stability, DECAY);
}

/** The whole-day interval at which recall probability equals `desiredRetention`. */
export function intervalFromStability(
  stability: number,
  desiredRetention: number,
  maximumInterval: number,
): number {
  const days = (stability / FACTOR) * (Math.pow(desiredRetention, 1 / DECAY) - 1);
  return clamp(Math.round(days), 1, maximumInterval);
}

export function initialStability(w: number[], rating: Rating): number {
  return Math.max(w[rating - 1]!, MIN_STABILITY);
}

export function initialDifficulty(w: number[], rating: Rating): number {
  return clamp(w[4]! - (rating - 3) * w[5]!, MIN_DIFFICULTY, MAX_DIFFICULTY);
}

export function nextDifficulty(w: number[], difficulty: number, rating: Rating): number {
  const delta = difficulty - w[6]! * (rating - 3);
  // Mean reversion towards the difficulty an "Easy" first answer would have given.
  const reverted = w[7]! * initialDifficulty(w, 4) + (1 - w[7]!) * delta;
  return clamp(reverted, MIN_DIFFICULTY, MAX_DIFFICULTY);
}

export function nextStabilityOnSuccess(
  w: number[],
  difficulty: number,
  stability: number,
  r: number,
  rating: Rating,
): number {
  const hardPenalty = rating === 2 ? w[15]! : 1;
  const easyBonus = rating === 4 ? w[16]! : 1;
  const growth =
    Math.exp(w[8]!) *
    (11 - difficulty) *
    Math.pow(stability, -w[9]!) *
    (Math.exp(w[10]! * (1 - r)) - 1) *
    hardPenalty *
    easyBonus;
  return Math.max(stability * (1 + growth), MIN_STABILITY);
}

export function nextStabilityOnFailure(
  w: number[],
  difficulty: number,
  stability: number,
  r: number,
): number {
  const postLapse =
    w[11]! *
    Math.pow(difficulty, -w[12]!) *
    (Math.pow(stability + 1, w[13]!) - 1) *
    Math.exp(w[14]! * (1 - r));
  // A lapse must never increase stability.
  return clamp(Math.min(postLapse, stability), MIN_STABILITY, Number.MAX_SAFE_INTEGER);
}
```

```ts
import {
  initialDifficulty,
  initialStability,
  intervalFromStability,
  nextDifficulty,
  nextStabilityOnFailure,
  nextStabilityOnSuccess,
  retrievability,
} from '@/lib/fsrs/core';
import type { DeckConfig, Rating, SchedulingState } from '@/lib/fsrs/types';
import { RATINGS } from '@/lib/fsrs/types';

const MINUTE = 60_000;
const DAY = 86_400_000;

export function newSchedulingState(now: number): SchedulingState {
  return {
    state: 'new',
    stability: 0,
    difficulty: 0,
    due: now,
    lastReview: null,
    reps: 0,
    lapses: 0,
    learningStep: 0,
    scheduledDays: 0,
  };
}

/** Applies `rating` to `state` and returns the new state. Never mutates the input. */
export function schedule(
  state: SchedulingState,
  rating: Rating,
  now: number,
  config: DeckConfig,
): SchedulingState {
  const w = config.fsrsParams;
  const isNew = state.state === 'new';

  let stability: number;
  let difficulty: number;
  if (isNew) {
    stability = initialStability(w, rating);
    difficulty = initialDifficulty(w, rating);
  } else {
    const elapsedDays = state.lastReview === null ? 0 : (now - state.lastReview) / DAY;
    const r = retrievability(elapsedDays, state.stability);
    difficulty = nextDifficulty(w, state.difficulty, rating);
    stability =
      rating === 1
        ? nextStabilityOnFailure(w, state.difficulty, state.stability, r)
        : nextStabilityOnSuccess(w, state.difficulty, state.stability, r, rating);
  }

  const next: SchedulingState = {
    ...state,
    stability,
    difficulty,
    lastReview: now,
    reps: state.reps + 1,
  };

  const graduate = (): SchedulingState => {
    const days = intervalFromStability(stability, config.desiredRetention, config.maximumInterval);
    return { ...next, state: 'review', learningStep: 0, scheduledDays: days, due: now + days * DAY };
  };

  const stepTo = (
    steps: number[],
    index: number,
    cardState: 'learning' | 'relearning',
  ): SchedulingState => {
    const minutes = steps[Math.min(index, steps.length - 1)] ?? 1;
    return {
      ...next,
      state: cardState,
      learningStep: index,
      scheduledDays: 0,
      due: now + minutes * MINUTE,
    };
  };

  if (state.state === 'review') {
    if (rating === 1) {
      next.lapses = state.lapses + 1;
      if (config.relearningSteps.length === 0) return graduate();
      return stepTo(config.relearningSteps, 0, 'relearning');
    }
    return graduate();
  }

  const inRelearning = state.state === 'relearning';
  const steps = inRelearning ? config.relearningSteps : config.learningSteps;
  const cardState = inRelearning ? 'relearning' : 'learning';

  if (steps.length === 0) return graduate();
  if (rating === 1) return stepTo(steps, 0, cardState);
  if (rating === 2) return stepTo(steps, state.learningStep, cardState);
  if (rating === 4) return graduate();

  // Good: advance one step, graduating past the end.
  const nextStep = (isNew ? 0 : state.learningStep) + (isNew ? 1 : 1);
  if (nextStep >= steps.length) return graduate();
  return stepTo(steps, nextStep, cardState);
}

/** What each rating would do, without committing to any of them. */
export function schedulePreview(
  state: SchedulingState,
  now: number,
  config: DeckConfig,
): Record<Rating, SchedulingState> {
  const preview = {} as Record<Rating, SchedulingState>;
  for (const rating of RATINGS) {
    preview[rating] = schedule(state, rating, now, config);
  }
  return preview;
}
```

Note on the `nextStep` line: a new card is at step `-1` conceptually, so Good on a new card moves it to step 0 — but the first learning step is index 0 and index 0's delay is the *first* interval, so a new card answered Good should land on step 1. Simplify that expression to:

```ts
  const nextStep = state.learningStep + 1;
```

and rely on `newSchedulingState` starting at `learningStep: 0`. Verify against the test "advances to the second learning step on Good", which expects `learningStep === 1` and a 10-minute delay.

```ts
export const MINUTE_MS = 60_000;
export const HOUR_MS = 3_600_000;
export const DAY_MS = 86_400_000;

/**
 * The start of the "study day" containing `timestamp`. A study day runs from
 * `rolloverHour` local time to `rolloverHour` the next day, so a 2am session
 * still belongs to the previous day's counts.
 */
export function startOfStudyDay(timestamp: number, rolloverHour: number): number {
  const date = new Date(timestamp);
  if (date.getHours() < rolloverHour) {
    date.setDate(date.getDate() - 1);
  }
  date.setHours(rolloverHour, 0, 0, 0);
  return date.getTime();
}

export function endOfStudyDay(timestamp: number, rolloverHour: number): number {
  return startOfStudyDay(timestamp, rolloverHour) + DAY_MS;
}

/** Stable `YYYY-MM-DD` key for the study day, used to bucket reviews. */
export function studyDayKey(timestamp: number, rolloverHour: number): string {
  const date = new Date(startOfStudyDay(timestamp, rolloverHour));
  const month = String(date.getMonth() + 1).padStart(2, '0');
  const day = String(date.getDate()).padStart(2, '0');
  return `${date.getFullYear()}-${month}-${day}`;
}

export function addDays(timestamp: number, days: number): number {
  return timestamp + days * DAY_MS;
}

/** Human-readable interval for the rating buttons, e.g. "10m", "3d", "2.5mo". */
export function formatInterval(days: number): string {
  if (days < 1 / 24) return `${Math.max(1, Math.round(days * 24 * 60))}m`;
  if (days < 1) return `${Math.round(days * 24)}h`;
  if (days < 30) return `${Math.round(days)}d`;
  if (days < 365) return `${(days / 30).toFixed(1)}mo`;
  return `${(days / 365).toFixed(1)}y`;
}
```

Note: `startOfStudyDay` uses `setHours` after `setDate`, which is DST-safe because both operate in local time and `setHours(h, 0, 0, 0)` re-resolves the offset.

```ts
import { DEFAULT_DECK_CONFIG } from '@/lib/fsrs';
import type { Deck } from '@/lib/db/types';

export interface CreateDeckInput {
  name: string;
  description?: string;
  directions?: Deck['directions'];
  config?: Deck['config'];
}

export async function createDeck(input: CreateDeckInput): Promise<number> {
  const name = input.name.trim();
  if (name === '') throw new Error('Deck name is required');
  return db.decks.add({
    name,
    description: input.description?.trim() ?? '',
    directions: input.directions ?? ['hanzi-meaning', 'hanzi-pinyin'],
    config: input.config ?? DEFAULT_DECK_CONFIG,
    createdAt: Date.now(),
  });
}

export function getDeck(id: number): Promise<Deck | undefined> {
  return db.decks.get(id);
}

export function listDecks(): Promise<Deck[]> {
  return db.decks.orderBy('createdAt').toArray();
}

export async function updateDeck(id: number, patch: Partial<Omit<Deck, 'id'>>): Promise<void> {
  if (patch.name !== undefined && patch.name.trim() === '') {
    throw new Error('Deck name is required');
  }
  await db.decks.update(id, patch);
}

/** Deletes the deck and everything that belongs to it, atomically. */
export async function deleteDeck(id: number): Promise<void> {
  await db.transaction('rw', db.decks, db.notes, db.cards, db.reviews, async () => {
    await db.reviews.where('deckId').equals(id).delete();
    await db.cards.where('deckId').equals(id).delete();
    await db.notes.where('deckId').equals(id).delete();
    await db.decks.delete(id);
  });
}
```

```ts
  colourHanzi: true,

    4: '#3b82f6', // fourth — blue
  },

export async function getSettings(): Promise<AppSettings> {
  const row = await db.settings.get('app');
  if (!row) return { ...DEFAULT_SETTINGS };
  return {
    ...DEFAULT_SETTINGS,
    ...row.value,
    toneColours: { ...DEFAULT_SETTINGS.toneColours, ...row.value.toneColours },
  };
}

export async function saveSettings(patch: Partial<AppSettings>): Promise<void> {
  if (patch.rolloverHour !== undefined) {
    const hour = patch.rolloverHour;
    if (!Number.isInteger(hour) || hour < 0 || hour > 23) {
      throw new Error('rolloverHour must be an integer between 0 and 23');
    }
  }
  const current = await getSettings();
  await db.settings.put({ key: 'app', value: { ...current, ...patch } });
}
```

```ts
  deckId: number;

  tags?: string[];

export async function createNote(input: CreateNoteInput): Promise<number> {
  const hanzi = input.hanzi.trim();
  const meaning = input.meaning.trim();
  if (hanzi === '') throw new Error('Hanzi is required');
  if (meaning === '') throw new Error('Meaning is required');

  return db.transaction('rw', db.decks, db.notes, db.cards, async () => {
    const deck = await db.decks.get(input.deckId);
    if (!deck) throw new Error(`Deck ${input.deckId} does not exist`);

    const duplicate = await db.notes.where({ deckId: input.deckId, hanzi }).first();
    if (duplicate) throw new Error(`"${hanzi}" is already in this deck`);

    const now = Date.now();
    const noteId = await db.notes.add({
      deckId: input.deckId,
      hanzi,
      pinyin: input.pinyin.trim(),
      meaning,
      notes: input.notes?.trim() ?? '',
      tags: input.tags ?? [],
      createdAt: now,
      updatedAt: now,
    });
    await db.cards.bulkAdd(
      deck.directions.map((direction) => buildCard(noteId, input.deckId, direction, now)),
    );
    return noteId;
  });
}

export async function updateNote(
  id: number,
  patch: Partial<Omit<Note, 'id' | 'deckId' | 'createdAt'>>,
): Promise<void> {
  if (patch.hanzi !== undefined && patch.hanzi.trim() === '') throw new Error('Hanzi is required');
  if (patch.meaning !== undefined && patch.meaning.trim() === '') {
    throw new Error('Meaning is required');
  }
  await db.notes.update(id, { ...patch, updatedAt: Date.now() });
}

export async function deleteNote(id: number): Promise<void> {
  await db.transaction('rw', db.notes, db.cards, db.reviews, async () => {
    await db.reviews.where('noteId').equals(id).delete();
    await db.cards.where('noteId').equals(id).delete();
    await db.notes.delete(id);
  });
}

/** Adds cards for newly enabled directions and removes cards for disabled ones. */
export async function syncCardsForNote(noteId: number): Promise<void> {
  await db.transaction('rw', db.decks, db.notes, db.cards, db.reviews, async () => {
    const note = await db.notes.get(noteId);
    if (!note) return;
    const deck = await db.decks.get(note.deckId);
    if (!deck) return;
    await reconcile(noteId, note.deckId, deck.directions);
  });
}

export async function syncCardsForDeck(deckId: number): Promise<void> {
  await db.transaction('rw', db.decks, db.notes, db.cards, db.reviews, async () => {
    const deck = await db.decks.get(deckId);
    if (!deck) return;
    const notes = await db.notes.where('deckId').equals(deckId).toArray();
    for (const note of notes) {
      await reconcile(note.id!, deckId, deck.directions);
    }
  });
}

async function reconcile(
  noteId: number,
  deckId: number,
  directions: Direction[],
): Promise<void> {
  const existing = await db.cards.where('noteId').equals(noteId).toArray();
  const wanted = new Set(directions);

  const stale = existing.filter((card) => !wanted.has(card.direction));
  if (stale.length > 0) {
    const ids = stale.map((card) => card.id!);
    await db.reviews.where('cardId').anyOf(ids).delete();
    await db.cards.bulkDelete(ids);
  }

  const present = new Set(existing.map((card) => card.direction));
  const missing = directions.filter((direction) => !present.has(direction));
  if (missing.length > 0) {
    const now = Date.now();
    await db.cards.bulkAdd(missing.map((d) => buildCard(noteId, deckId, d, now)));
  }
}
```

```ts
export const SHARD_COUNT = 64;

/**
 * Buckets an entry by its first character so a lookup only downloads one shard.
 * Shared by the build script and the runtime loader — they must never diverge.
 */
export function shardKeyFor(hanzi: string): string {
  const code = hanzi.codePointAt(0);
  if (code === undefined) return 'xx';
  return (code % SHARD_COUNT).toString(16).padStart(2, '0');
}
```

```ts
import { numberedToAccented } from '@/lib/pinyin';
import type { DictEntry } from '@/lib/dictionary/types';

const LINE = /^(\S+)\s+(\S+)\s+\[([^\]]*)\]\s+\/(.*)\/\s*$/;

export function parseCedictLine(line: string): DictEntry | null {
  const trimmed = line.trim();
  if (trimmed === '' || trimmed.startsWith('#')) return null;
  const match = LINE.exec(trimmed);
  if (!match) return null;
  const [, traditional, simplified, pinyin, glosses] = match;
  return {
    traditional: traditional!,
    simplified: simplified!,
    pinyin: numberedToAccented(pinyin!),
    meanings: glosses!.split('/').filter((gloss) => gloss !== ''),
  };
}
```

```ts
import { shardKeyFor } from '@/lib/dictionary/shard';
import type { DictEntry } from '@/lib/dictionary/types';

/** Swappable so tests do not need a real network or file server. */
let fetchImpl: typeof fetch = (...args) => globalThis.fetch(...args);

export function setDictionaryFetch(fn: typeof fetch): void {
  fetchImpl = fn;
}

const shards = new Map<string, Promise<DictEntry[]>>();

export function clearDictionaryCache(): void {
  shards.clear();
}

function loadShard(key: string): Promise<DictEntry[]> {
  const cached = shards.get(key);
  if (cached) return cached;
  const pending = (async (): Promise<DictEntry[]> => {
    try {
      const response = await fetchImpl(`/dict/${key}.json`);
      if (!response.ok) return [];
      return (await response.json()) as DictEntry[];
    } catch {
      // Offline with an uncached shard: degrade to "no suggestions".
      return [];
    }
  })();
  shards.set(key, pending);
  return pending;
}

export async function lookupExact(hanzi: string): Promise<DictEntry | null> {
  const query = hanzi.trim();
  if (query === '') return null;
  const entries = await loadShard(shardKeyFor(query));
  return entries.find((entry) => entry.simplified === query) ?? null;
}

export async function lookupPrefix(prefix: string, limit = 20): Promise<DictEntry[]> {
  const query = prefix.trim();
  if (query === '') return [];
  const entries = await loadShard(shardKeyFor(query));
  return entries
    .filter((entry) => entry.simplified.startsWith(query))
    .sort((a, b) => a.simplified.length - b.simplified.length)
    .slice(0, limit);
}
```

```ts
/**
 * Converts CC-CEDICT into per-shard JSON under public/dict/.
 *
 *   curl -L https://www.mdbg.net/chinese/export/cedict/cedict_1_0_ts_utf-8_mdbg.txt.gz \
 *     | gunzip > cedict.u8
 *   npm run build:dict -- cedict.u8
 *
 * CC-CEDICT is licensed CC BY-SA 4.0; the attribution lives on the Settings page.
 */
import { mkdir, readFile, rm, writeFile } from 'node:fs/promises';
import { join } from 'node:path';
import { parseCedictLine } from '../src/lib/dictionary/parse';
import { shardKeyFor } from '../src/lib/dictionary/shard';
import type { DictEntry } from '../src/lib/dictionary/types';

const source = process.argv[2];
if (!source) {
  console.error('usage: npm run build:dict -- <path-to-cedict.u8>');
  process.exit(1);
}

const outputDir = join(process.cwd(), 'public', 'dict');
const text = await readFile(source, 'utf8');

const buckets = new Map<string, DictEntry[]>();
let parsed = 0;
let skipped = 0;

for (const line of text.split('\n')) {
  const entry = parseCedictLine(line);
  if (!entry) {
    if (line.trim() !== '' && !line.startsWith('#')) skipped++;
    continue;
  }
  // Trim the long tail of glosses; the editor only ever shows the first few.
  entry.meanings = entry.meanings.slice(0, 6);
  const key = shardKeyFor(entry.simplified);
  const bucket = buckets.get(key) ?? [];
  bucket.push(entry);
  buckets.set(key, bucket);
  parsed++;
}

await rm(outputDir, { recursive: true, force: true });
await mkdir(outputDir, { recursive: true });

let bytes = 0;
for (const [key, entries] of buckets) {
  entries.sort((a, b) => a.simplified.localeCompare(b.simplified));
  const json = JSON.stringify(entries);
  bytes += json.length;
  await writeFile(join(outputDir, `${key}.json`), json, 'utf8');
}

console.log(
  `${parsed} entries, ${skipped} skipped, ${buckets.size} shards, ` +
    `${(bytes / 1024 / 1024).toFixed(1)} MB total, ` +
    `${(bytes / buckets.size / 1024).toFixed(0)} KB average shard`,
);
```

```ts
import { db } from '@/lib/db/db';
import type { Card, Note } from '@/lib/db/types';

export interface QueueItem {
  card: Card;
  note: Note;
}

export interface DeckCounts {
  new: number;
  learning: number;
  review: number;
}

function isDueLearning(card: Card, now: number): boolean {
  return (card.state === 'learning' || card.state === 'relearning') && card.due <= now;
}

function isDueReview(card: Card, now: number): boolean {
  return card.state === 'review' && card.due <= now;
}

/**
 * Every card the user can study right now, ordered: overdue (re)learning steps
 * first so they do not drift, then reviews most-overdue first, then new cards.
 * There is no daily cap by design.
 */
export async function buildQueue(deckId: number, now: number): Promise<QueueItem[]> {
  const cards = (await db.cards.where('deckId').equals(deckId).toArray()).filter(
    (card) => card.suspended === 0,
  );

  const learning = cards.filter((card) => isDueLearning(card, now)).sort((a, b) => a.due - b.due);
  const review = cards.filter((card) => isDueReview(card, now)).sort((a, b) => a.due - b.due);
  const fresh = cards.filter((card) => card.state === 'new').sort((a, b) => a.id! - b.id!);

  const ordered = [...learning, ...review, ...fresh];
  if (ordered.length === 0) return [];

  const notes = await db.notes.bulkGet([...new Set(ordered.map((card) => card.noteId))]);
  const byId = new Map(notes.filter((note): note is Note => note !== undefined).map((n) => [n.id!, n]));

  return ordered.flatMap((card) => {
    const note = byId.get(card.noteId);
    return note ? [{ card, note }] : [];
  });
}

export async function deckCounts(deckId: number, now: number): Promise<DeckCounts> {
  const cards = (await db.cards.where('deckId').equals(deckId).toArray()).filter(
    (card) => card.suspended === 0,
  );
  return {
    new: cards.filter((card) => card.state === 'new').length,
    learning: cards.filter((card) => isDueLearning(card, now)).length,
    review: cards.filter((card) => isDueReview(card, now)).length,
  };
}
```

```ts
import { db } from '@/lib/db/db';
import { schedule, schedulePreview } from '@/lib/fsrs';
import type { DeckConfig, Rating, SchedulingState } from '@/lib/fsrs';
import { buildQueue, type QueueItem } from '@/lib/study/queue';
import type { Card, ReviewLog } from '@/lib/db/types';
import { DAY_MS } from '@/lib/time';

/** A card scheduled sooner than this comes back in the same sitting. */
export const RE_QUEUE_WINDOW_MS = 20 * 60_000;
const MAX_RECORDED_DURATION_MS = 60_000;

interface UndoEntry {
  item: QueueItem;
  previousCard: Card;
  logId: number;
  queueIndex: number;
}

export class StudySession {
  private queue: QueueItem[];
  private readonly config: DeckConfig;
  private readonly undoStack: UndoEntry[] = [];

  private constructor(queue: QueueItem[], config: DeckConfig) {
    this.queue = queue;
    this.config = config;
  }

  static async start(deckId: number, now: number): Promise<StudySession> {
    const deck = await db.decks.get(deckId);
    if (!deck) throw new Error(`Deck ${deckId} does not exist`);
    return new StudySession(await buildQueue(deckId, now), deck.config);
  }

  get current(): QueueItem | null {
    return this.queue[0] ?? null;
  }

  get isFinished(): boolean {
    return this.queue.length === 0;
  }

  get counts(): { new: number; learning: number; review: number; answered: number } {
    let fresh = 0;
    let learning = 0;
    let review = 0;
    for (const { card } of this.queue) {
      if (card.state === 'new') fresh++;
      else if (card.state === 'review') review++;
      else learning++;
    }
    return { new: fresh, learning, review, answered: this.undoStack.length };
  }

  /** What each rating would schedule, for the button labels. */
  previews(now: number): Record<Rating, SchedulingState> {
    const item = this.current;
    if (!item) throw new Error('No current card');
    return schedulePreview(item.card, now, this.config);
  }

  async answer(rating: Rating, now: number, durationMs: number): Promise<void> {
    const item = this.current;
    if (!item) throw new Error('No current card');

    const previous = { ...item.card };
    const next = schedule(previous, rating, now, this.config);
    const elapsedDays = previous.lastReview === null ? 0 : (now - previous.lastReview) / DAY_MS;

    const log: Omit<ReviewLog, 'id'> = {
      cardId: previous.id!,
      noteId: previous.noteId,
      deckId: previous.deckId,
      direction: previous.direction,
      rating,
      stateBefore: previous.state,
      stateAfter: next.state,
      reviewedAt: now,
      elapsedDays,
      scheduledDays: next.scheduledDays,
      stabilityAfter: next.stability,
      difficultyAfter: next.difficulty,
      durationMs: Math.min(Math.max(durationMs, 0), MAX_RECORDED_DURATION_MS),
    };

    let logId = 0;
    await db.transaction('rw', db.cards, db.reviews, async () => {
      await db.cards.update(previous.id!, next);
      logId = await db.reviews.add(log as ReviewLog);
    });

    const updated: QueueItem = { note: item.note, card: { ...previous, ...next } };
    this.queue = this.queue.slice(1);

    let queueIndex = -1;
    if (next.due - now < RE_QUEUE_WINDOW_MS) {
      queueIndex = this.queue.findIndex((queued) => queued.card.due > next.due);
      if (queueIndex === -1) queueIndex = this.queue.length;
      this.queue.splice(queueIndex, 0, updated);
    }

    this.undoStack.push({ item, previousCard: previous, logId, queueIndex });
  }

  /** Reverts the last answer. Returns false when there is nothing to revert. */
  async undo(): Promise<boolean> {
    const entry = this.undoStack.pop();
    if (!entry) return false;

    await db.transaction('rw', db.cards, db.reviews, async () => {
      await db.cards.put(entry.previousCard);
      await db.reviews.delete(entry.logId);
    });

    if (entry.queueIndex >= 0) {
      this.queue.splice(entry.queueIndex, 1);
    }
    this.queue.unshift(entry.item);
    return true;
  }
}
```

```tsx
import { useSettings } from '@/hooks/useSettings';

/**
 * Renders hanzi, optionally colouring the nth character with the tone of the
 * nth pinyin syllable. When the counts disagree (rare: erhua, punctuation) the
 * extra characters are left uncoloured rather than mis-coloured.
 */
export default function HanziText({
  hanzi,
  pinyin,
  className = '',
}: {
  hanzi: string;
  pinyin: string;
  className?: string;
}) {
  const { settings } = useSettings();
  const syllables = parseAccentedPinyin(pinyin).filter((token) => token.tone !== null);
  const characters = [...hanzi];

  if (!settings.colourHanzi || syllables.length !== characters.length) {
    return <span className={className}>{hanzi}</span>;
  }

  return (
    <span className={className}>
      {characters.map((character, index) => (
        <span
          key={index}
          data-tone={syllables[index]!.tone}
          style={{ color: settings.toneColours[syllables[index]!.tone!] }}
        >
          {character}
        </span>
      ))}
    </span>
  );
}
```

```ts
import { useLiveQuery } from 'dexie-react-hooks';
import { db } from '@/lib/db/db';
import { deckCounts, type DeckCounts } from '@/lib/study';

const ZERO: DeckCounts = { new: 0, learning: 0, review: 0 };

/** Live due counts. Re-runs whenever any card changes. */
export function useDeckCounts(deckId: number | undefined): DeckCounts {
  return (
    useLiveQuery(async () => {
      if (deckId === undefined) return ZERO;
      // Touch the table so Dexie subscribes to card mutations.
      await db.cards.where('deckId').equals(deckId).count();
      return deckCounts(deckId, Date.now());
    }, [deckId]) ?? ZERO
  );
}
```

```tsx
import { useNavigate, useParams } from 'react-router';
import { useLiveQuery } from 'dexie-react-hooks';
import { deleteDeck, getDeck, updateDeck } from '@/lib/db/decks';
import { ALL_DIRECTIONS, DIRECTION_LABELS } from '@/lib/db/types';
import Button from '@/components/Button';
import Field, { inputClass } from '@/components/Field';
import PageHeader from '@/components/PageHeader';
import type { Direction } from '@/lib/db/types';

export default function DeckSettingsPage() {
  const { deckId: param } = useParams();
  const deckId = Number(param);
  const navigate = useNavigate();
  const deck = useLiveQuery(() => getDeck(deckId), [deckId]);

  if (!deck) return <PageHeader title="Deck settings" backTo="/" />;

  async function toggleDirection(direction: Direction, enabled: boolean) {
    const next = enabled
      ? [...deck!.directions, direction]
      : deck!.directions.filter((d) => d !== direction);
    if (next.length === 0) return;
    if (!enabled) {
      const confirmed = window.confirm(
        `Disabling "${DIRECTION_LABELS[direction]}" deletes those cards and their review history. Continue?`,
      );
      if (!confirmed) return;
    }
    await updateDeck(deckId, { directions: ALL_DIRECTIONS.filter((d) => next.includes(d)) });
  }

  return (
    <>
      <PageHeader title="Deck settings" backTo={`/deck/${deckId}`} />
      <div className="space-y-6 p-4">
        <Field label="Name">
          <input
            className={inputClass}
            defaultValue={deck.name}
            onBlur={(event) => updateDeck(deckId, { name: event.target.value })}
          />
        </Field>

        <fieldset>
          <legend className="mb-2 text-sm font-medium text-slate-600 dark:text-slate-300">
            Card directions
          </legend>
          <div className="space-y-2">
            {ALL_DIRECTIONS.map((direction) => (
              <label key={direction} className="flex min-h-11 items-center gap-3">
                <input
                  type="checkbox"
                  className="size-5"
                  checked={deck.directions.includes(direction)}
                  onChange={(event) => toggleDirection(direction, event.target.checked)}
                />
                <span>{DIRECTION_LABELS[direction]}</span>
              </label>
            ))}
          </div>
          <p className="mt-2 text-xs text-slate-500">
            Nothing prompts for the character itself — writing practice comes later.
          </p>
        </fieldset>

        <Field label="Desired retention" hint="Higher means shorter intervals. 0.9 is a good default.">
          <input
            className={inputClass}
            type="number"
            min={0.7}
            max={0.98}
            step={0.01}
            defaultValue={deck.config.desiredRetention}
            onBlur={(event) =>
              updateDeck(deckId, {
                config: { ...deck.config, desiredRetention: Number(event.target.value) },
              })
            }
          />
        </Field>

        <Field label="Learning steps (minutes, comma separated)">
          <input
            className={inputClass}
            defaultValue={deck.config.learningSteps.join(', ')}
            onBlur={(event) =>
```

```tsx
import { useEffect, useState } from 'react';
import { lookupPrefix } from '@/lib/dictionary';
import type { DictEntry } from '@/lib/dictionary';
import PinyinText from '@/components/PinyinText';

/** Debounced prefix search. Renders nothing until there is something to show. */
export default function DictionarySuggestions({
  query,
  onPick,
}: {
  query: string;
  onPick: (entry: DictEntry) => void;
}) {
  const [entries, setEntries] = useState<DictEntry[]>([]);

  useEffect(() => {
    if (query.trim() === '') {
      setEntries([]);
      return;
    }
    let cancelled = false;
    const timer = setTimeout(async () => {
      const results = await lookupPrefix(query, 8);
      if (!cancelled) setEntries(results);
    }, 150);
    return () => {
      cancelled = true;
      clearTimeout(timer);
    };
  }, [query]);

  if (entries.length === 0) return null;

  return (
    <ul className="divide-y divide-slate-200 rounded-xl border border-slate-200 dark:divide-slate-700 dark:border-slate-700">
      {entries.map((entry) => (
        <li key={entry.simplified}>
          <button
            type="button"
            onClick={() => onPick(entry)}
            className="flex w-full min-h-11 items-baseline gap-2 px-3 py-2 text-left"
          >
            <span className="text-lg">{entry.simplified}</span>
            <PinyinText pinyin={entry.pinyin} className="text-sm" />
            <span className="flex-1 truncate text-sm text-slate-500">
              {entry.meanings.join('; ')}
            </span>
          </button>
        </li>
      ))}
    </ul>
  );
}
```

```tsx
            autoFocus={!isEditing}
            onChange={(event) => setHanzi(event.target.value)}

              Delete
```

```ts
export type NoteField = 'hanzi' | 'pinyin' | 'meaning';
```

```tsx
  const deckId = Number(param);

    if (!session) return;
    await session.undo();
    setItem(session.current);
    setRevealed(false);
```

```ts
/** RFC 4180 subset: comma separated, optional double quotes, doubled quotes escape. */
export function parseCsv(text: string): string[][] {
  const rows: string[][] = [];
  let row: string[] = [];
  let field = '';
  let inQuotes = false;
  let hasContent = false;

  const endField = (): void => {
    row.push(field);
    field = '';
  };
  const endRow = (): void => {
    endField();
    if (hasContent) rows.push(row);
    row = [];
    hasContent = false;
  };

  for (let i = 0; i < text.length; i++) {
    const char = text[i]!;
    if (inQuotes) {
      if (char === '"') {
        if (text[i + 1] === '"') {
          field += '"';
          i++;
        } else {
          inQuotes = false;
        }
      } else {
        field += char;
      }
      hasContent = true;
      continue;
    }
    if (char === '"') {
      inQuotes = true;
      hasContent = true;
    } else if (char === ',') {
      endField();
      hasContent = true;
    } else if (char === '\n') {
      endRow();
    } else if (char !== '\r') {
      field += char;
      if (char.trim() !== '') hasContent = true;
    }
  }
  endRow();
  return rows;
}

export function toCsv(rows: string[][]): string {
  return rows
    .map((row) =>
      row
        .map((field) =>
          /[",\n\r]/.test(field) ? `"${field.replace(/"/g, '""')}"` : field,
        )
        .join(','),
    )
    .join('\n');
}
```

```ts
import { db } from '@/lib/db/db';
import { createNote } from '@/lib/db/notes';
import { parseCsv, toCsv } from '@/lib/io/csv';

export interface ImportResult {
  imported: number;
  skipped: number;
  errors: string[];
}

const HEADER = ['hanzi', 'pinyin', 'meaning', 'notes'];
const MAX_REPORTED_ERRORS = 20;

function isHeaderRow(row: string[]): boolean {
  return row[0]?.trim().toLowerCase() === 'hanzi';
}

/** Imports `hanzi,pinyin,meaning[,notes]` rows. Bad rows are reported, not fatal. */
export async function importCsvIntoDeck(deckId: number, text: string): Promise<ImportResult> {
  const rows = parseCsv(text);
  const result: ImportResult = { imported: 0, skipped: 0, errors: [] };
  const seen = new Set<string>();

  for (const [index, row] of rows.entries()) {
    if (index === 0 && isHeaderRow(row)) continue;

    const [hanzi = '', pinyin = '', meaning = '', notes = ''] = row.map((field) => field.trim());
    if (hanzi === '' || meaning === '') {
      result.skipped++;
      if (result.errors.length < MAX_REPORTED_ERRORS) {
        result.errors.push(`Row ${index + 1}: needs at least a hanzi and a meaning`);
      }
      continue;
    }
    if (seen.has(hanzi)) {
      result.skipped++;
      if (result.errors.length < MAX_REPORTED_ERRORS) {
        result.errors.push(`Row ${index + 1}: "${hanzi}" appears more than once in the file`);
      }
      continue;
    }
    seen.add(hanzi);

    try {
      await createNote({ deckId, hanzi, pinyin, meaning, notes });
      result.imported++;
    } catch (cause) {
      result.skipped++;
      if (result.errors.length < MAX_REPORTED_ERRORS) {
        result.errors.push(
          `Row ${index + 1}: ${cause instanceof Error ? cause.message : 'could not be imported'}`,
        );
      }
    }
  }

  return result;
}

export async function exportDeckCsv(deckId: number): Promise<string> {
  const notes = await db.notes.where('deckId').equals(deckId).sortBy('createdAt');
  return toCsv([HEADER, ...notes.map((n) => [n.hanzi, n.pinyin, n.meaning, n.notes])]);
}
```

```ts
import { db } from '@/lib/db/db';
import type { AppSettings, Card, Deck, Note, ReviewLog } from '@/lib/db/types';

export const BACKUP_VERSION = 1;

interface Backup {
  version: number;
  exportedAt: number;
  decks: Deck[];
  notes: Note[];
  cards: Card[];
  reviews: ReviewLog[];
  settings: { key: 'app'; value: AppSettings }[];
}

export async function exportBackup(): Promise<string> {
  const [decks, notes, cards, reviews, settings] = await Promise.all([
    db.decks.toArray(),
    db.notes.toArray(),
    db.cards.toArray(),
    db.reviews.toArray(),
    db.settings.toArray(),
  ]);
  const backup: Backup = {
    version: BACKUP_VERSION,
    exportedAt: Date.now(),
    decks,
    notes,
    cards,
    reviews,
    settings,
  };
  return JSON.stringify(backup);
}

function parseBackup(json: string): Backup {
  let parsed: unknown;
  try {
    parsed = JSON.parse(json);
  } catch {
    throw new Error('That file is not a Chinanki backup');
  }
  if (
    typeof parsed !== 'object' ||
    parsed === null ||
    !('version' in parsed) ||
    !('decks' in parsed)
  ) {
    throw new Error('That file is not a Chinanki backup');
  }
  const backup = parsed as Backup;
  if (backup.version > BACKUP_VERSION) {
    throw new Error('That backup came from a newer version of Chinanki');
  }
  return backup;
}

/** Replaces the entire database. The caller is responsible for confirming first. */
export async function importBackup(json: string): Promise<void> {
  const backup = parseBackup(json);
  await db.transaction('rw', db.decks, db.notes, db.cards, db.reviews, db.settings, async () => {
    await Promise.all([
      db.decks.clear(),
      db.notes.clear(),
      db.cards.clear(),
      db.reviews.clear(),
      db.settings.clear(),
    ]);
    await db.decks.bulkAdd(backup.decks ?? []);
    await db.notes.bulkAdd(backup.notes ?? []);
    await db.cards.bulkAdd(backup.cards ?? []);
    await db.reviews.bulkAdd(backup.reviews ?? []);
    await db.settings.bulkAdd(backup.settings ?? []);
  });
}

/** Triggers a browser download. No-op outside a DOM. */
export function downloadText(filename: string, text: string): void {
  const url = URL.createObjectURL(new Blob([text], { type: 'text/plain;charset=utf-8' }));
  const link = document.createElement('a');
  link.href = url;
  link.download = filename;
  link.click();
  URL.revokeObjectURL(url);
}
```

```ts
import { DAY_MS, startOfStudyDay, studyDayKey } from '@/lib/time';
import type { ReviewLog } from '@/lib/db/types';
import type { HeatmapDay } from '@/lib/stats/types';

/** Thresholds are absolute rather than relative so the colours mean the same thing over time. */
function levelFor(count: number): HeatmapDay['level'] {
  if (count === 0) return 0;
  if (count < 10) return 1;
  if (count < 25) return 2;
  if (count < 40) return 3;
  return 4;
}

export function buildHeatmap(
  reviews: ReviewLog[],
  now: number,
  rolloverHour: number,
  days = 365,
): HeatmapDay[] {
  const counts = new Map<string, number>();
  const oldest = startOfStudyDay(now, rolloverHour) - (days - 1) * DAY_MS;
  for (const review of reviews) {
    if (review.reviewedAt < oldest) continue;
    const key = studyDayKey(review.reviewedAt, rolloverHour);
    counts.set(key, (counts.get(key) ?? 0) + 1);
  }

  const result: HeatmapDay[] = [];
  for (let offset = days - 1; offset >= 0; offset--) {
    const key = studyDayKey(now - offset * DAY_MS, rolloverHour);
    const count = counts.get(key) ?? 0;
    result.push({ date: key, count, level: levelFor(count) });
  }
  return result;
}

/** Consecutive study days with at least one review, allowing today to be still empty. */
export function currentStreak(reviews: ReviewLog[], now: number, rolloverHour: number): number {
  const active = new Set(reviews.map((review) => studyDayKey(review.reviewedAt, rolloverHour)));
  if (active.size === 0) return 0;

  const today = studyDayKey(now, rolloverHour);
  let offset = active.has(today) ? 0 : 1;
  if (!active.has(studyDayKey(now - offset * DAY_MS, rolloverHour))) return 0;

  let streak = 0;
  while (active.has(studyDayKey(now - offset * DAY_MS, rolloverHour))) {
    streak++;
    offset++;
  }
  return streak;
}

export function reviewsPerDayAverage(
  reviews: ReviewLog[],
  now: number,
  rolloverHour: number,
  days: number,
): number {
  const oldest = startOfStudyDay(now, rolloverHour) - (days - 1) * DAY_MS;
  const recent = reviews.filter((review) => review.reviewedAt >= oldest).length;
  return recent / days;
}
```

```ts
import { DAY_MS, startOfStudyDay, studyDayKey } from '@/lib/time';
import type { Card } from '@/lib/db/types';
import type { ForecastDay } from '@/lib/stats/types';

/** Upcoming workload. Overdue cards all land on day 0. New cards are not scheduled. */
export function buildForecast(
  cards: Card[],
  now: number,
  rolloverHour: number,
  days = 30,
): ForecastDay[] {
  const today = startOfStudyDay(now, rolloverHour);
  const counts = new Array<number>(days).fill(0);

  for (const card of cards) {
    if (card.suspended === 1 || card.state === 'new') continue;
    const offset = Math.floor((startOfStudyDay(card.due, rolloverHour) - today) / DAY_MS);
    const index = Math.max(0, offset);
    if (index < days) counts[index] = counts[index]! + 1;
  }

  let running = 0;
  return counts.map((dueCount, index) => {
    running += dueCount;
    return { date: studyDayKey(today + index * DAY_MS, rolloverHour), dueCount, cumulative: running };
  });
}
```

```ts
import type { ReviewLog } from '@/lib/db/types';
import type { RetentionSummary } from '@/lib/stats/types';

/**
 * Only answers to cards that were already scheduled count: failing a card during
 * its first learning steps says nothing about long-term recall.
 */
function isMeasurable(review: ReviewLog): boolean {
  return review.stateBefore === 'review' || review.stateBefore === 'relearning';
}

export function retentionOverall(reviews: ReviewLog[]): RetentionSummary {
  const measurable = reviews.filter(isMeasurable);
  const correct = measurable.filter((review) => review.rating > 1).length;
  return {
    reviewed: measurable.length,
    correct,
    rate: measurable.length === 0 ? 0 : correct / measurable.length,
  };
}

export function retentionByMonth(
  reviews: ReviewLog[],
): { month: string; rate: number; reviewed: number }[] {
  const buckets = new Map<string, { correct: number; reviewed: number }>();

  for (const review of reviews.filter(isMeasurable)) {
    const date = new Date(review.reviewedAt);
    const month = `${date.getFullYear()}-${String(date.getMonth() + 1).padStart(2, '0')}`;
    const bucket = buckets.get(month) ?? { correct: 0, reviewed: 0 };
    bucket.reviewed++;
    if (review.rating > 1) bucket.correct++;
    buckets.set(month, bucket);
  }

  return [...buckets.entries()]
    .sort(([a], [b]) => a.localeCompare(b))
    .map(([month, bucket]) => ({
      month,
      reviewed: bucket.reviewed,
      rate: bucket.correct / bucket.reviewed,
    }));
}
```

```ts
import type { Card } from '@/lib/db/types';
import type { CardBreakdown } from '@/lib/stats/types';

/** Anki's convention: a review card is "mature" once its interval reaches 21 days. */
const MATURE_DAYS = 21;

export function cardBreakdown(cards: Card[]): CardBreakdown {
  const breakdown: CardBreakdown = { new: 0, learning: 0, young: 0, mature: 0, suspended: 0 };

  for (const card of cards) {
    if (card.suspended === 1) {
      breakdown.suspended++;
      continue;
    }
    if (card.state === 'new') breakdown.new++;
    else if (card.state === 'learning' || card.state === 'relearning') breakdown.learning++;
    else if (card.scheduledDays < MATURE_DAYS) breakdown.young++;
    else breakdown.mature++;
  }

  return breakdown;
}
```

`e2e/smoke.spec.ts`:

```ts
import { expect, test } from '@playwright/test';

test('create a deck, add a word, study it, and see it in the stats', async ({ page }) => {
  await page.goto('/');

  await page.getByRole('button', { name: 'New deck' }).click();
  await page.getByLabel('Deck name').fill('E2E deck');
  await page.getByRole('button', { name: 'Create' }).click();
  await expect(page.getByText('E2E deck')).toBeVisible();

  await page.getByText('E2E deck').click();
  await page.getByRole('button', { name: 'Add word' }).click();
  await page.getByLabel('Hanzi').fill('好');
  await page.getByLabel('Pinyin').fill('hǎo');
  await page.getByLabel('Meaning').fill('good');
  await page.getByRole('button', { name: 'Save' }).click();

  // Two directions by default, so two cards.
  await expect(page.getByTestId('count-new')).toHaveText('2');

  await page.getByRole('button', { name: /Study/ }).click();
  await expect(page.getByTestId('prompt')).toContainText('好');
  await expect(page.getByTestId('answer')).toHaveCount(0);

  await page.getByRole('button', { name: 'Show answer' }).click();
  await expect(page.getByTestId('answer')).toBeVisible();
  await page.getByRole('button', { name: /Easy/ }).click();

  await page.getByRole('button', { name: 'Show answer' }).click();
  await page.getByRole('button', { name: /Easy/ }).click();
  await expect(page.getByText('All done')).toBeVisible();

  await page.getByRole('button', { name: 'Back to deck' }).click();
  await expect(page.getByText('Nothing due right now')).toBeVisible();

  await page.getByRole('link', { name: /Stats/ }).click();
  await expect(page.getByTestId('stat-today')).toHaveText('2');
  await expect(page.getByTestId('stat-streak')).toHaveText('1');
});

test('persists data across a reload', async ({ page }) => {
  await page.goto('/');
  await page.getByRole('button', { name: 'New deck' }).click();
  await page.getByLabel('Deck name').fill('Persistent');
  await page.getByRole('button', { name: 'Create' }).click();

  await page.reload();
  await expect(page.getByText('Persistent')).toBeVisible();
});

test('registers a service worker so the app works offline', async ({ page }) => {
  await page.goto('/');
  await expect(page.getByRole('heading', { name: 'Decks' })).toBeVisible();
  const registered = await page.evaluate(async () => {
    const registration = await navigator.serviceWorker.ready;
    return registration.active !== null;
  });
  expect(registered).toBe(true);
});
```

## Post-implementation notes

**Deliberately out of scope for v1** — do not add these while executing the plan:

- Handwriting input (the eventual `* → hanzi` direction). The `Direction` union and `promptFor`/`answerFor` split are the extension points.
- Traditional characters. Adding them means a `traditional` field on `Note` and a display setting; CC-CEDICT already carries the data, so the import path is the only place that needs to change.
- Audio / TTS.
- FSRS parameter optimisation from the user's own review history. `ReviewLog` already stores everything the optimiser needs (`stateBefore`, `elapsedDays`, `rating`), and `DeckConfig.fsrsParams` is already per-deck.
- Daily new-card limits. If unlimited queues become unmanageable, the cap belongs in `buildQueue`, which is the only place that decides what is studiable.
- Sync between devices.

**Known trade-offs baked into this plan:**

- `buildQueue` loads every card in the deck into memory and filters in JS rather than using the compound indexes. For decks up to a few thousand cards this is a millisecond or two and far simpler to reason about. If a deck ever gets slow, switch to `db.cards.where('[deckId+due]').below(...)`; the tests will not need to change.
- `syncCardsForDeck` deletes the review logs of disabled directions. That loses history, which is why the UI confirms first. The alternative — orphaned logs — would corrupt the statistics.
- Statistics load the whole `reviews` table. At ~100 bytes per row, a year of 200 reviews/day is about 7 MB, which is fine. If it stops being fine, index by `[deckId+reviewedAt]` (already present) and window the query.
